# 🎯 Eventus — сервис персонализированных рекомендаций мероприятий

Веб-сервис для автоматического подбора мероприятий студентам на основе анализа их цифрового профиля и компетенций.

---

## 🚀 Как запустить проект

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Milena827/Eventus.git
   cd eventus
   ```

2. Создайте файл .env в корне проекта с ключами API:
   ```bash
   env
   VK_ACCESS_TOKEN=ваш_токен_vk
   GIGACHAT_CLIENT_ID=ваш_client_id
   GIGACHAT_SECRET=ваш_client_secret
   ```

3. Запустите проект через Docker:
   ```bash
   docker-compose up -d
   ```

4. Откройте фронтенд в браузере: http://localhost:5173

## 🛠 Технологии
Backend:

Python 3.11 - язык программирования

FastAPI - веб-фреймворк для REST API

SQLAlchemy - ORM для работы с PostgreSQL

Pydantic - валидация данных

GigaChat API - AI-анализ компетенций мероприятий

httpx + BeautifulSoup4 - парсинг веб-страниц

VK API - сбор мероприятий из сообществ ВКонтакте

Frontend:

Vue.js 3 - прогрессивный JavaScript-фреймворк

Bootstrap 5 - адаптивная стилизация

Axios - HTTP-клиент для запросов к API

Инфраструктура:

PostgreSQL 15 - база данных

Docker + Docker Compose - контейнеризация

GitHub Actions - автоматический запуск парсеров по расписанию

## 📊 Функциональность

Регистрация и заполнение профиля (email, курс, факультет)

Импорт результатов тестирования компетенций

Две персональные подборки мероприятий: На основе слабых компетенций и на основе интересов

Избранное, оценки и обратная связь о мероприятиях

Отслеживание прогресса развития компетенций
